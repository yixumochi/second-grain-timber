Dataset coverage, classification and reproducibility

The inventory contains 762 listings and 2,161 saved image/mask pairs. The 375 saved cloud records include 172 partial-evidence cases, 25 failed common-scene cases and 178 unresolved cross-view cases; 387 listings have no saved CPU reconstruction run. These categories describe evidence quality, not timber grades.

Existing pretrained SAM 2 and VGGT outputs are reused. The website does not train a model or run new inference. Repeated views of a listing do not establish that they show the same physical board.

Original MILP formulation and search limits

The existing Cubbyhouse formulation uses integer variables for cutting-pattern counts and member jointing-pattern counts. Constraints ensure that produced parts cover required parts, stock use stays within recorded quantities, and member demand is met.

minimize: cutting-pattern waste
+ surplus-part length
+ number of parts required by selected member patterns

The original objective is retained, including its length and part-count terms. It is not a carbon score or a verified fabrication-cost model. Pattern menus are bounded; an optimal result refers to the submitted menu. The solver does not discover an unrestricted global form.

Case 1 permits supported multi-part members. Case 2 and Case 3 retain one continuous stock part per required strip/member. Angle machining and section changes require explicit geometry and separate accounting.
