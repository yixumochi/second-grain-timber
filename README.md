# SECOND GRAIN

A static research presentation connecting reclaimed timber evidence, stock-first design, saved allocations and preliminary structural analysis.

[Open the research website](https://yixumochi.github.io/second-grain-timber/showcase/)

The main presentation lives in `showcase/`. Its seven hash routes are Overview, Material AI, Design Agent, Cases and the three individual cases. Existing detailed viewers remain at the root, `case2/explore/` and `case3/`; their links return to the research overview. The previous material and method viewers remain available in expandable archive sections.

There is no build step. GitHub Pages publishes `main` from the repository root. Asset URLs use the `/second-grain-timber/` base path, so a local server must mount this folder at that path.

## Presentation refinement

The November 2026 Impeccable pass adds a research overview, a shared reading hierarchy, self-hosted Newsreader and Public Sans, readable evidence captions, canonical navigation, lazy viewer loading and static fallbacks for response animations. Original research JSON, drawings, photographs and films are unchanged.

Run the navigation regression checks with `node --test tests/navigation.test.cjs`. Syntax checks and source validation covered local resource paths, seven chapter headings, 26 saved results and the main text-color pairs. Late animation initialization and reduced-motion timing were also checked in isolated JavaScript simulations.

The initial visual pass lacked browser verification. The subsequent AI-pathways pass was inspected in a real browser at 1280 px and 390 px, including material stages, the two demand probes, three Agent requests, paired geometry views and archive deep links. Impeccable's CLI detector remains unavailable because its engine is not installed; this is a manual skill-guided review, not a clean detector result.

## Two AI research pathways

The material chapter follows specimen 99397 from seller photographs through saved SAM2 masks and VGGT point support. A separately identified specimen, 115200, demonstrates a crack-like candidate and two isolated cutting probes. The 20 mm trim buffer is a research assumption; no automatic grade or complete reconstruction is claimed.

The design chapter compares three actual API request interpretations, then shows separately recorded material-driven bench geometry and a Shelter structural revision. The bench diagrams render all 716 saved extruded polygons at one camera and scale. The source working scale is unconfirmed; the geometry adaptation reports zero model calls. The complete autonomous connection between these experiments is not presented as an executed pipeline.

`showcase/assets/ai-process/process.json` contains curated records and provenance hashes. `bench-geometry.json` contains exact paired display geometry. The 16 evidence images are unchanged copies of saved source assets. `scripts/export-ai-evidence.py` reproduces the exports from explicit source arguments without publishing workstation paths or API payloads.

## Research boundaries

This site presents saved research records. Representative material appearance, atmosphere studies, preliminary calculations and unresolved physical verification remain distinguished in the source content. It does not run a new allocation or certify fabrication.

Font licenses are included in `assets/fonts/`. Font sources: [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader) and [Public Sans](https://github.com/google/fonts/tree/main/ofl/publicsans).
